# Бактерии онлайн 5

Стартовый Android-проект для мобильной io-игры. Сейчас готов первый слой:

- экран регистрации / входа;
- главное меню в стиле референса;
- выбор сервера и кнопка `играть`;
- вкладки слева: главное меню, ежедневные награды, профиль, настройки;
- загрузка аватарки в профиле;
- валюта из ежедневной награды и прокачка генов персонажа;
- настройки музыки, звуков, управления и графики;
- первый игровой экран: мир 10000x10000, сетка 100x100 с блоками 100x100, островная генерация на шуме и шаблонах блоков, бактерия игрока, камера, чат, лидеры и выбираемый джойстик движения;
- ДНК как еда: +1 к опыту, повышение уровня по формуле `уровень * 50`, награда валютой после уровня;
- цвет игрока зависит от генов: скорость добавляет синий, масса красный, иммунитет зеленый; на максимуме генов открывается магазин скинов;
- отдельный Java-сервер для будущей онлайн-комнаты.

## Сборка в Android Studio

Откройте папку проекта `D:\бактерии онлайн 5` в Android Studio и запустите модуль `app`.

## Команды

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :server:run
```

## Протокол сервера

Сервер слушает TCP-порт `5055` и принимает строки JSON:

```json
{"type":"join","name":"USERNAME"}
{"type":"move","x":1200,"y":900}
{"type":"chat","text":"hello"}
{"type":"action","name":"split"}
{"type":"ping"}
```

В ответ сервер отправляет `welcome`, `joined`, `pong` и регулярный `state` со списком игроков.
В консоли сервера отображаются все активные подключения, их адреса, позиции и последние действия.
